# 👁️ Eye Disease Classification Using CNN

## 📌 Project Overview

This project focuses on **Eye Disease Classification using Convolutional Neural Networks (CNN)**. It uses Deep Learning and Computer Vision techniques to analyze eye images and classify them into different categories.

The CNN model learns important image features automatically and uses them to predict the corresponding class.

## 🎯 Objectives

- Classify eye images using Deep Learning.
- Apply image preprocessing techniques.
- Build a CNN-based image classification model.
- Train and evaluate the CNN model.
- Predict classes for new eye images.

## 🧠 Model Used: Convolutional Neural Network (CNN)

CNN is a deep learning algorithm mainly used for image processing and image classification.

The CNN architecture can include:

1. Convolutional Layer
2. ReLU Activation Function
3. Max Pooling Layer
4. Flatten Layer
5. Fully Connected (Dense) Layer
6. Output Layer

## ⚙️ Project Workflow

1. Import required libraries.
2. Load the eye disease image dataset.
3. Explore the dataset.
4. Preprocess and resize images.
5. Normalize image pixel values.
6. Split data into training and testing sets.
7. Build the CNN architecture.
8. Compile the CNN model.
9. Train the model using training images.
10. Evaluate model performance.
11. Predict eye disease classes from images.
